# Odoo Apps: Helpdesk

Odoo modules extending the `helpdesk` module.

## Usage

Clone this repo into the Odoo addons directory.

```bash
git clone git@github.com:Mint-System/Odoo-Apps-Helpdesk.git ./addons/helpdesk
```
