# Odoo Apps: Helpdesk

Odoo modules extending the `helpdesk` module.

## Usage

Clone this repo into the Odoo addons directory.

```bash
git clone git@github.com:Mint-System/Odoo-Apps-Helpdesk.git ./addons/helpdesk
```

## Available modules

| Module | Summary |
| --- | --- |
| [helpdesk_ticket_pureict](helpdesk_ticket_pureict) |         Add change management related fields to Ticket. |
| [helpdesk_ticket_stage_note](helpdesk_ticket_stage_note) |         Prompt for a chatter text at specific stage changes. |
